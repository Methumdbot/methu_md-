## 💙 About METHU MD

METHU MD is a WhatsApp automation bot project
built with Node.js and Baileys.

Our goal is to make WhatsApp easier and smarter.

## ✨ Current Commands

| Command | Description |
|---------|-------------|
| `.ping` | Check bot status |
| `.menu` | Show command menu |
| `.alive` | Check bot alive |
| `.help` | Help menu |

## 🚀 Features

- QR Code Login support
- Pairing Code Login support
- WhatsApp connection
- Automatic session saving
- Easy command system
- Custom bot settings

## 📦 Installation

```bash
git clone https://github.com/Methumdbot/methu_md.git

cd methu_md

npm install

npm start
```

## 🔑 Login

1. Start the bot.
2. Enter your WhatsApp number with country code.
3. Get the pairing code.
4. Link your WhatsApp account.
